# NepDora QA Testing Portfolio

## About This Project

This repository contains QA testing documentation prepared during testing of the NepDora website.

The purpose of this project is to document test scenarios, report identified issues, summarize testing activities, and record performance testing observations.

## Testing Activities

- **Manual Testing:** Functional and user interface testing.
- **Test Case Documentation:** Test cases for website features.
- **Bug Reporting:** Documentation of identified defects.
- **Performance Testing:** Performance testing observations using Apache JMeter.
- **API Testing:** API testing activities performed during the project.

## Tools Used

- Apache JMeter
- Postman
- Browser Developer Tools
